# 3D Plastics Pixel Guide

Ламповая pixel-art энциклопедия материалов для FDM/FFF 3D-печати.

## Реализовано

- каталог из **58 пластиков, композитов и support-материалов**;
- поиск и фильтры по семейству и сложности печати;
- подробные карточки: сопло, стол, камера, сушка и назначение;
- сравнение до трёх материалов;
- интерактивный подбор связующего слоя поддержек;
- быстрый выбор пластика под задачу;
- адаптивное pixel-art оформление;
- работа без сборщика и зависимостей.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Файлы

```text
index.html    — структура сайта
styles.css    — pixel-art дизайн и адаптив
materials.js — база пластиков и правила поддержек
app.js       — поиск, фильтры, сравнение и интерактив
```

## Важное замечание

Температуры являются стартовыми диапазонами. Приоритет всегда имеет паспорт конкретного филамента и тестовая печать.
